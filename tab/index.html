Chords and notes mode hears several strings at once and tidies the whole take when you stop. Write tab from the loop does the same for the looper's recording. A clean or lightly driven tone works best; the readout doubles as a tuner.

The layout

Header: song title and artist, a status line (file name, notes, bars and the bar the cursor is in, or the live readout while listening), the STAFF / METERS switch, and the file buttons: NEW, OPEN, SAVE, SAVE PDF, PRINT, FOLDER and HELP.

Toolbar: techniques, palm mute and let ring, chord names and text, editing tools, tuning, capo, tempo, grid, Listen, and the full-screen button at the right end.

Tab staff: six lines, high e at the top and low E at the bottom, divided into bars. The green box is the cursor: new notes are written there. Scroll sideways with the bar under the staff (or Shift + mouse wheel).

Transport strip (under the tab): playback, the looper, the drum machine and the click, with a readout in the middle showing the count-in, the bar and what's playing, plus the Mixer / Neck buttons.

Mixer (under the transport strip): volume, pan, trim and effects for each part, explained below. Neck drops the fretboard down in its place.

Fretboard: 22 frets in the current tuning. Point at any spot to see the note name, string and fret. Notes already written in the cursor's column light up in gold.

Writing notes

Click a fret on the fretboard to write it at the cursor. Click left of the nut (the open column) for an open string. The cursor then moves right by the Step amount (1, 2 or 4 grid columns; 2 is a good default).

Click anywhere on the tab to put the cursor on that string and column.

Type fret numbers: press 0-9 to write at the cursor. Two digits typed quickly make 10-22 (press 1 then 2 for 12).

Chords: turn on Stack (or press Q) and the cursor stays in the same column, so each fret you click stacks into one chord. Turn it off, then press Space or the right arrow to move on.

Writing on a spot that already has a note replaces it.

Selecting, moving and editing

Select a note by clicking it (it turns gold). Shift-click or Ctrl-click to add or remove notes. Drag across empty space to select everything inside the box.

Move notes: press on a note, hold, drag it to a new column or string and release. Selected notes move together. Dropping onto another note replaces that note.

Delete (⌫, Delete or Backspace) removes the selected notes, or the note under the cursor.

⇥ inserts space at the cursor, pushing everything to the right along. ⇤ removes space at the cursor, pulling everything back (notes in the removed space are deleted).

+ bar adds a bar at the end; bars are also added automatically as you write past the end. − bar removes the last bar (it asks first if the bar has notes).

↶ Undo and ↷ Redo (Ctrl+Z and Ctrl+Y) cover every change.

Techniques

Select one or more notes (or put the cursor on a note), then press a technique button. Press it again to remove it. The button lights up when every selected note has it.

h hammer-on, p pull-off, / slide up, \ slide down, b bend, r release: drawn between the note and the next note on the same string, so 5h7 is a 5 marked h with a 7 after it on that string. If there's no next note, the mark sits just after the note.

~ vibrato, drawn after the note. x muted (dead) note: with nothing selected it writes an x at the cursor. <> natural harmonic, shown as <12>. ( ) ghost note, shown as (5). T tap, shown as a small T above the note.

Palm mute, let ring, chord names and text

P.M. and L.R. (let ring) draw a dashed line above the staff over the selected notes. With nothing selected they cover a short stretch from the cursor.

Chord writes a chord name (for example G5 or Am7) above the cursor's column. Text writes a note such as "build up" or "x2".

Click a mark above the staff to select it (it turns gold), then press Delete to remove it.

Song settings

Title and Artist: type in the header. The title becomes the file name.

Tuning: Standard, Drop D, Half step down, Full step down, Drop C#, Drop C, DADGAD, Open G, Open D, Open E and Open C. The string names on the tab and fretboard follow it, and so does Listen.

Capo: frets are written relative to the capo, as in normal tab. Note names and Listen take the capo into account.

BPM: the tempo, printed on the PDF and used by Listen to place notes where you played them. Leave it blank and Listen works it out for you.

Grid: columns per bar (8, 12, 16 or 24). Changing it keeps every note in the same bar and relative spot. Use 16 for most songs and 12 or 24 for triplet feels.

Listen: write notes as you play

Setup, once: connect the Spark 2 to the PC with a USB cable (Bluetooth only sends audio to the amp, not back). In Windows Settings → Privacy & security → Microphone, turn on Microphone access and "Let desktop apps access your microphone": Windows treats the Spark's USB input as a microphone.

Start: press ● Listen. It glows green while listening. Each note you pick is written at the cursor and the cursor moves on. Press it again to stop.

The readout in the header shows the note you're playing, how many cents sharp or flat, and the string and fret it will write. A green dot follows along on the fretboard, so it works as a tuner too.

⚙ settings: What to listen for picks Single notes (instant) or Chords and notes (AI), explained below. Input picks the Spark automatically when Windows lists it; choose another input here if needed. The level meter shows the signal. Fret position: the same note can be played in several places, so "Automatic" picks the spot nearest to where you've been playing, or lock it to open, 3rd, 5th, 7th, 9th or 12th position. Timing: "As played" (the default) writes each note exactly when you played it, at the BPM (see Tempo below); "Even steps" writes each note one Step apart. Sensitivity: raise it if soft notes are missed, lower it if noise writes notes.

Tips: use a clean or lightly driven tone (heavy gain, delay and chorus confuse pitch detection). In the default single-note mode, play single notes; for chords, switch to Chords and notes mode (below). Hammer-ons, pull-offs and slides are marked for you: a note that changes without a new pick gets h or p, one that glides there gets / or \, and both notes are kept on one string (a slide's starting note moves off an open string if needed). Bends and vibrato aren't detected; add them with the buttons. If the meter barely moves, turn up the Spark's input or its USB level.

Microphone: if the computer, tablet or phone has a microphone, the Listen ⚙ menu shows SOURCE: GUITAR / USB INPUT or MICROPHONE. Pick the microphone to play an acoustic guitar, or an amp, near it; the app cuts the low room rumble so it isn't written as notes. The looper records from the same source.

Tempo, exact timing and quantize

Listen now writes every note exactly when you played it, at the song's tempo (Timing: As played, the new default). The tempo never changes while you play: if you've typed a BPM, it's used as it is.

BPM blank? Then the app works the tempo out from what you play: from the attacks in the sound and the timing of your notes. In chords and notes mode it writes the notes once it has the tempo (about 5 seconds in) and checks it against the whole take when you stop; then it puts the result in the BPM box, where it stays. If your timing was loose it says so, so you can type the BPM or play to the click.

Q (next to TAB | NOTES) quantizes: each press steps through OFF, 1/16, 1/8, 1/4 and triplets (when the GRID allows them), snapping the notes you recorded by listening to the nearest one. It never throws your timing away: every recorded note remembers when you really played it, so Q OFF puts them all back exactly as played. Notes you place or drag by hand stay where you put them.

Sheet music

The TAB | ♪ NOTES switch in the top right corner of the staff flips between the tab and standard sheet music (treble clef with a small 8 under it, the usual way guitar is written: it sounds an octave lower than it reads). Both are always written together: everything you click in, type or play while Listen is on goes into the tab and the sheet music at the same time, so you can switch back and forth whenever you like, even while listening.

The sheet music shows each note's pitch, sharps or flats (once per bar, with naturals to cancel them), chords stacked on one stem, ledger lines, and rhythm from the grid: whole, half, quarter, eighth and sixteenth notes, dotted notes, eighths and sixteenths beamed by the beat, triplets on the 12 and 24 grids, and rests for the gaps. Chord names, P.M. and let ring show above the staff; hammer-ons and pull-offs are marked H and P, slides sl., bends B, harmonics with diamond heads and dead notes with x heads.

Click a note on the sheet music to select it (it lights up gold on both views), or click anywhere to move the cursor there. Do your editing on the tab, or by playing, and watch the notes appear. SAVE PDF and PRINT follow the switch: with ♪ NOTES on, every line prints as a full guitar score with the sheet music over the tab.

Playing back the tab

▶ Play (or Enter) plays the tab from the start of the cursor's bar to the last bar with notes, at the BPM (100 if it's blank). A green playhead runs across the tab and the sounding notes light up green on the fretboard. To play just part of the song, select some notes first: it plays the bars they're in. Press it again (it reads Stop tab) to stop.

⟲ repeats the playback until you stop it, handy for practising a passage. The tone menu picks My guitar, Clean, Crunch or Lead.

My guitar (the default) is modeled on your own guitar, from a recording you played into the app: how long the strings ring, how the high harmonics fade faster than the lows, the pick attack, the thump of the body, and the full, warm, soft-topped sound coming out of the Spark. The other tones use the same strings with a brighter clean sound or overdrive.

Playback follows the techniques: hammer-ons and pull-offs sound without a new pick, slides glide, bends and releases bend the pitch, vibrato wobbles, palm-muted notes are short and dark, x notes are dead thuds, harmonics chime and ghost notes are quiet. Notes in one column are strummed low to high.

Looper

The looper records your guitar from the Spark 2 (the input chosen in Listen ⚙) and plays it back in time with the drums and click. Pick the loop length in BARS (1, 2, 4, 8, 12 or 16) and the COUNT-IN (1 to 4 bars of clicks).

● Rec: you hear the count-in (the readout counts down the beats), then it records exactly that many bars and starts looping straight away. The tempo is the BPM, and it stays locked while a loop exists.

Overdub: adds a new layer on top while the loop plays; press again to stop. Every time round counts as its own layer, so you can keep stacking parts. If the loop is paused, Overdub counts you in and starts at the top of the loop.

▶ / ❚❚ plays or pauses the loop. ↶ removes the last layer (pressed while overdubbing, it throws away the pass you're on). Clear erases the loop so you can record a new one at a new length or tempo.

Timing: the looper allows for the PC's audio delay automatically. If your overdubs land slightly behind the beat, open ⚙ on the strip and move Looper sync to the right; if they land ahead, move it left.

Meters

Press METERS (next to NEW) to swap the tab staff for a row of DUSTEX level gauges, and STAFF to swap back. The widget remembers which one you had showing.

There's a gauge for every channel: INPUT, AUX, GUITAR, LOOPER, DRUMS and CLICK, the four effects, and MASTER L and MASTER R. Each one reads from -40 to 0 dB: the green zone is a healthy level (up to -18 dB), gold is getting loud (-18 to -6 dB) and red is close to the top (-6 to 0 dB). The orange needle shows the level as it moves. The thin red needle holds the latest peak for a moment, and the number under the gauge shows that peak in dB. The small lamp near the bottom of the face lights red if the channel clips (hits full scale), and stays lit until you reset it.

Click anywhere on the gauges to reset the peak needles and clip lamps. Aim for most of the action in the green and gold, with the master peaking in the gold. If something keeps clipping, pull its fader down on the Mixer (or turn on LIMIT on the master).

Full screen

The full-screen button at the right end of the toolbar fills the whole monitor with the big full-page layout: the staff, the gauges, the transport strip, the fretboard and the mixer all at once. Press it again, or press Esc, to put the widget back in its spot on the dashboard. In the web app it switches the browser to full screen.

EQ

Press EQ (next to METERS) to swap the staff for the EQ window (in the full-page layout it takes the place of the gauges). Pick a channel along the top: INPUT, AUX, GUITAR, LOOPER, DRUMS, CLICK or MASTER, then the EQ type. ON switches that channel's EQ in or out and FLAT resets the type you're on. The EQ button on each mixer strip opens it straight on that channel, and lights when its EQ is on.

The curve shows what the EQ does; the green shading behind it is the channel's live sound. A channel with its EQ off uses no processing at all.

Parametric: seven bands, high-pass, low shelf, three peaks, high shelf and low-pass. Drag a dot on the curve to set its frequency and gain, use the wheel over a dot for its width (Q), or use the knobs; double-click a band's name to switch it on or off.

Graphic: ten sliders from 31 Hz to 16 kHz, ±12 dB each (double-click a slider to zero it).

Dynamic: three bands that react to the music: when a band gets louder than its THR (threshold) it is turned down (a negative RANGE) or brought up (a positive RANGE), by an amount set with RATIO; GAIN is its steady boost or cut. Great for taming boomy strums or harsh picks only when they happen.

Linear phase: ten sliders like the graphic EQ, but shaping the sound without shifting its timing, which keeps transients and stereo images clean. It needs a few milliseconds of look-ahead, so every other channel is delayed by the same amount automatically to keep everything in time.

Analog: a tube-style program EQ: LOW picks 20, 30, 60 or 100 Hz with BOOST and ATTEN (use both for the classic big-but-tight low end), HIGH picks the top boost frequency with WIDTH, ATT SEL and ATTEN roll off the very top, DRIVE adds warm tube saturation and OUTPUT sets the level.

Mixer

The panel under the transport strip is a mixer. Press Neck (next to Click) to drop the fretboard down over it, and Mixer to bring the mixer back. The widget remembers which one you had open.

Channel strips: INPUT (your guitar from the Spark 2), AUX (a line in), GUITAR (tab playback), LOOPER, DRUMS and CLICK. Each one has a volume fader with a level meter, IN (input trim, ±12 dB), PAN, four effect knobs, REV, PLT, DLY and ECH (how much goes to the room reverb, the plate, the delay and the echo), plus M mute and S solo (solo plays only the soloed strips).

INPUT strip: ● IN opens the guitar input so its meter shows your level; the looper opens it too. Its IN trim also sets how loud the looper records. The knobs and fader caps are the same chrome DUSTEX parts as the Fishing Forecaster. MON plays your guitar through the PC with the mixer's effects. It starts off, because the Spark already plays your guitar and you'd hear it twice, slightly late.

AUX strip: a second input for anything else you want to play along with or through the mixer: a keyboard, a phone or MP3 player with a backing track, a drum machine, a second guitar or a microphone. Plug it into the PC's line in (or a USB audio interface), press ● IN and pick the input from the list; click the name under AUX to choose a different one later. It's in stereo, and MON starts on so you hear it straight away, with the same trim, pan, effect sends and fader as the other strips. AUX has its own gauge on the meter row too. It plays alongside the looper but isn't recorded into it.

Hide a strip: the small – in the top left corner of every strip folds it down to a narrow tab with its name (the sound keeps playing); click the tab or its + to open it again. Hidden strips stay hidden the next time.

Effects (the four gold strips; each fader sets how loud that effect comes back):

REVERB, a room: SIZE (how long it lasts), PRE (a short gap before it starts), TONE and PAN.

PLATE, the bright, smooth reverb of a studio steel plate: DECAY, PRE, DAMP (brightness) and PAN.

DELAY, echoes locked to the BPM: TIME steps through 1/16, 1/8, dotted 1/8, 1/4, dotted 1/4 and 1/2, plus FDBK (repeats), TONE and PAN.

ECHO, a tape echo with a warm, slightly wobbly sound: TIME (free, in milliseconds), FDBK, WOW (tape wobble) and TONE (darker repeats).

MASTER is the output, with left and right meters. LIMIT keeps loud moments from clipping. RESET MIX puts every control back to its starting value.

Using the controls: drag a fader or slider, or drag a knob up and down, or use the mouse wheel over it. Hover over a knob to see its value. Double-click any control to reset it (faders go to 0 dB, effect sends to 0). The mixer settings are saved.

Drum machine and click

Drums starts and stops the drum machine; the menu next to it picks the beat. Rock: basic rock, driving eighths, 16ths, half-time, four on the floor and ballad. Blues: shuffle, slow 12/8, Texas shuffle, Chicago and boogie. Drums follow the BPM and come in with a crash.

Click is the metronome, with a higher click on beat 1. Drums, click, playback and the looper all run on one clock, so they always line up, and you can start them in any order: whatever starts later comes in at the next bar.

■ stops everything at once. Volumes, pan and effects are on the Mixer; ⚙ on the strip has Looper sync.

Chords and notes mode (AI)

Open Listen ⚙ and set What to listen for to Chords and notes (AI). Listen then hears several strings at once, so strummed chords, double-stops and riffs all get written. It runs Spotify's open-source Basic Pitch note model, stored in the widget folder, so it works offline and your audio never leaves the PC. The first time, it takes a few seconds to load.

While you play the tab fills in about a second behind you. When you stop, it goes over the whole take once more and rewrites it neatly: one fingering for the whole phrase, with as little hand movement as possible, and chord shapes your hand can actually make. One ↶ Undo removes the whole take.

Write tab from the loop (in the same menu) transcribes whatever the looper has recorded and writes it from the start of the cursor's bar, in time with the BPM. Record one part per loop for the cleanest result.

Chord names: chords it recognises (major, minor, 7ths, power chords, sus, dim and more, including slash chords like D/F#) are named above the tab. Turn this off with Chord names. Bends and vibrato are picked up from the pitch and marked b and ~; quick, softer notes on the same string are marked h or p.

Settings that still apply: Fret position locks where it writes, Timing chooses even steps or your real timing at the BPM, and Sensitivity sets how quiet a note can be and still count. If it adds stray notes, lower Sensitivity; if it misses strings, raise it.

Takes: every take is saved in the Takes folder inside Tab Widget: the audio exactly as the model heard it, plus a record of every note it detected, which ones the clean-up kept, and what it wrote where. The newest 30 are kept. If a take comes out wrong, tell Claude "check the last take": it can line up the sound, the detections and the tab on one timeline and see exactly what to adjust.

What to expect: on a clean or lightly driven tone it gets most notes right; fast runs and heavy distortion need more fixing by hand. It writes the notes it hears, so a string that barely sounded in a strum may be left out. Drag notes to fix anything.

Saving, opening and printing

SAVE (Ctrl+S) stores the tab as Song Title.dxtab. OPEN lists your saved tabs, newest first. NEW starts a blank tab (it asks if there are unsaved changes).

SAVE PDF (Ctrl+P) writes Song Title.pdf: a clean black-on-white Letter page with the title, artist, tuning, capo and tempo, four bars per line, ready to print or share. With ♪ NOTES switched on, each line is a guitar score: sheet music above, tab below. PRINT opens the Windows print dialog directly.

FOLDER opens the Tab Widget folder, where everything is kept: your .dxtab files, the PDFs and the widget itself.

Autosave: your work is kept as you go, so closing the widget or restarting the PC never loses it. It comes back the next time the widget opens.

iPhone and iPad

Open the web app in Safari and tap Share › Add to Home Screen; it runs full screen and offline. On iPad it shows the full-page layout; on iPhone the panels run down the page at full size and the wide parts (the staff, the gauges, the mixer, the fretboard) swipe sideways. Knobs, faders, sliders, the EQ curve and the staff all work with a finger. Listen uses the built-in microphone, or a guitar interface plugged into the iPhone or iPad. There are also native Tab Studio and Forecaster apps in the GitHub project (folder ios) for putting them in the App Store.

On another PC (the web app)

Tab Creator Studio also runs as an app on any Windows PC: open deesayi.github.io/dustex-fishing/tab in Microsoft Edge or Google Chrome and click the Install icon in the address bar. It gets its own window and Start menu icon, works offline and updates itself. There, SAVE keeps tabs inside the app, and OPEN also has Open a file from this PC and Save a copy to this PC (to Downloads). SAVE PDF uses the print window (choose Save as PDF). The web app uses the full-page layout: the staff, meters, fretboard and mixer all show at once, bigger, so the STAFF/METERS and Mixer/Neck switches aren't needed there. The install guide PDF walks through it step by step.

On the desktop

The widget docks into its port under the Fishing panel on the right screen. It starts by itself when you sign in to Windows (through a DUSTEX Tab shortcut in the Startup folder), and you can also start it from the Tab Widget shortcut in the Dashboard folder. Both shortcuts are made the first time the widget runs. Right-click an empty part of the widget for Reload, Open the Tab Widget folder or Close.

If something's wrong: "no audio input found" means the Spark isn't connected by USB or Windows doesn't see it. "Microphone access was blocked" means the Windows microphone setting above is off. If notes come out an octave off or jump strings, lock the Fret position. For anything else, the widget keeps a log, tab-widget.log, in the Tab Widget folder.
